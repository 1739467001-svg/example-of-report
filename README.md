## 🎯 项目速览

> 一个基于全校真实课表数据、覆盖督导全流程的研究生教学督导一体化平台。

**真实数据底座**

| 课程 | 学院 | 校区 | 教师 | 用户 | 排课 |
| :--: | :--: | :--: | :--: | :--: | :--: |
| 1,431 门 | 22 个 | 2 个 | 588 名 | 58 位 | 单双周 |

**四类角色**：督导专家 · 督导组长 · 学院教学秘书 · 研究生院主管

**核心能力**：全校课程多维筛选 · 听课计划（待办 + 日历）· 标准化课程评价（20 项定量 + 定性）· 评价记录权限分级 · 数据看板与统计 · 消息通知与提醒 · 工号登录与用户管理

**督导业务闭环**：全校课表 → 多维筛选 → 加入听课计划 → 课堂听课 → 在线评价 → 自动通知 → 学院/研究生院查看 → 数据统计分析 → 持续改进

**技术与设计**：前后端分离 · PostgreSQL · TypeScript / Material Design 3 · 商务蓝响应式（电脑/平板/手机）

**部署上线**：已部署于阿里云并上线运行，持续运维迭代（面向真实业务的可用系统）

## 🔧 如何重新生成（可选）

```bash
pip install cairosvg matplotlib python-pptx Pillow playwright
# 需要中文字体（如 文泉驿正黑 / 思源黑体）
python scripts/gen_diagrams.py   # 生成示意图
python scripts/gen_charts.py     # 生成雷达图
python scripts/gen_html.py       # 生成网页版 PPT（内嵌图片）
python scripts/gen_pptx.py       # 生成可编辑 PPT
python scripts/make_pdf.py       # 由 HTML 导出 PDF
```
